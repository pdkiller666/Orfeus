# Орфей — Android

Нативная Android-оболочка с локальным HTML/WebAudio-тренажёром вокала и динамическим публичным каталогом аудиообразцов GitHub.

## Сборка и тесты

Требуются JDK 17, Gradle 8.9 и Android SDK Platform 34. Из корня проекта:

```bash
node --test tests/*.test.cjs
gradle assembleDebug --no-daemon
```

APK создаётся по пути `app/build/outputs/apk/debug/app-debug.apk`. Это debug APK для тестирования, не публикация в Google Play.

## Важные ограничения

Определение высоты ноты и проценты упражнения — технические ориентиры по аудиосигналу, не оценка качества или безопасности техники и не классификация типа голоса. Тренажёр не заменяет педагога. Контент экстремальных вокальных эффектов отключён до профессиональной проверки. В онлайн-каталоге есть явно помеченные тестовые синтетические сигналы; это не голос человека и не педагогические эталоны. Образцы преподавателей из `https://github.com/pdkiller666/Orfeus/tree/main/samples` сохраняются в кэше для офлайн-прослушивания.

Прогресс хранится локально; системное резервное копирование приложения отключено. Его можно перенести вручную через экспорт/импорт. Опциональные записи «до/после» выключены по умолчанию и остаются только в памяти текущего запуска приложения; они не включаются в экспорт.

## Загрузка преподавательского образца

На экране упражнения откройте карточку «Образец и аудиозаписи» и нажмите «Добавить». Для прямой отправки настройте **fine-grained Personal Access Token** с доступом только к `pdkiller666/Orfeus`, правами репозитория `Contents: Read and write` и `Pull requests: Read and write`, а также правом участника `Write` в репозитории. Не используйте classic token и не публикуйте токен в чате или репозитории. Приложение проверяет токен через GitHub API и сохраняет его только в зашифрованном хранилище Android Keystore на этом устройстве.

Редактор позволяет либо записать звук после нажатия, либо выбрать готовый WAV/MP3/M4A/AAC/OGG/OPUS/WEBM/FLAC-файл через системный Android picker. Импорт не запрашивает широкого разрешения на хранилище; исходный файл обрабатывается локально, ограничен 25 МБ и 2 минутами, его можно прослушать и обрезать до фрагмента 0,5–30 секунд. При отправке только выбранный фрагмент нормализуется в WAV (до 5 МБ); оригинал и остальные части записи не отправляются. Файл становится публичным только после отдельного подтверждения отправки в GitHub. Закрытие окна во время системного запроса разрешения отменяет ожидающий захват микрофона; при уходе приложения в фон активная запись прекращается.

**Важно: в публичном репозитории GitHub загружаемый файл становится общедоступным сразу после отправки в ветку, до проверки и слияния PR.** Pull Request нужен для включения метаданных и аудио в каталог основной ветки приложения; это не скрывает исходный файл. Удаление публичного файла не гарантирует удаления ранее скопированных копий. UI требует отдельное подтверждение такого риска, права на публикацию, согласия исполнителя и CC BY 4.0. Применяйте защиту `main` с обязательным review code owner, иначе у пользователя с Write может быть возможность обойти PR.

После первоначального выпуска обновления новые файлы каталога доступны всем версиям приложения с онлайн-каталогом без новой сборки. Приложения до версии 1.2 нужно обновить вручную один раз. В версии 1.3 карточка отдельно маркирует синтетический тестовый сигнал и образец преподавателя. Версия 1.4 добавляет проверку GitHub Releases и ненавязчивое предложение скачать обновление. В версии 1.5 ошибка доступа к микрофону объясняется, и пользователь может открыть настройки разрешений Android прямо из приложения. Версия 1.6 исправляет регрессию, которая могла преждевременно блокировать запрос Android на доступ к микрофону. В версии 1.7 опубликованный teacher sample в том же упражнении заменяет синтетическую demo-кнопку; синтез остаётся, пока записи преподавателя нет в основной ветке каталога. Версия 1.8 добавляет импорт готового аудиофайла через системный picker, локальное прослушивание/обрезку и отправку только нормализованного WAV-фрагмента. Версия 1.9 показывает финальное подтверждение публикации через нативный Android dialog, чтобы отправка не зависала на неподдержанном WebView confirm; каталог также объясняет, что образцы из PR станут активными после слияния и предлагает обновить его вручную.

APK публикуется для прямой установки в GitHub Releases после каждого успешного запуска сборки на `main`. Обновление не устанавливается автоматически: пользователь открывает APK-ссылку и подтверждает установку средствами Android. Для установки из браузера Android может запросить разрешение «Установка неизвестных приложений» для данного источника. Устанавливайте APK поверх текущей версии, не удаляя приложение.


## Версия 1.10

Исправлена загрузка каталога: запрос к `raw.githubusercontent.com` больше не задаёт вручную заголовок `Cache-Control`, который вызывал неуспешный CORS preflight в WebView. Обновление по-прежнему обходит кэш через `cache: "no-store"` и параметр URL. В уроках добавлены отдельные отметки выполненных упражнений и общий прогресс; отметки сохраняются локально и попадают в существующий экспорт/импорт. XP по-прежнему начисляется только при явной отметке всего урока.


## Версия 1.11

В упражнениях с опубликованным образцом оставлена одна основная жёлтая кнопка Play/Stop. Сведения о записи и дополнительный нативный аудиоплеер находятся в сворачиваемой панели непосредственно под ней; панель закрыта по умолчанию. Если свернуть её во время воспроизведения, звук останавливается.


## Версия 1.12

Кнопки «Образец» и «Старт» объединены в компактную группу основных действий. Сведения и плеер размещены отдельно от формы добавления записи. Редактор записи открывается нижней панелью поверх текущего экрана; закрытие панели не пересоздаёт упражнение и сохраняет его состояние.


## Версия 1.13

Раздел «Тренировки» открывается компактным выбором категорий; внутри доступны поиск, закреплённые фильтры и карточки отдельных упражнений. Длинные пояснения и вспомогательные инструменты в уроках сведены к раскрываемым секциям. Единый набор SVG-иконок работает офлайн в WebView и заменяет emoji в навигации, карточках, кнопках и элементах аудио. Главные действия «Эталон» и «Старт» сохранены рядом, с более ясными подписями, крупными зонами касания и фокусом клавиатуры. Визуальная проверка на целевом Android-устройстве остаётся необходимой.


## Версия 1.14

Кнопки «Образец» и «Старт» сохранены рядом, но различаются по визуальному приоритету; во время воспроизведения образца кнопка подсвечивается золотым и меняет состояние. Стандартные системные controls заменены на единый офлайн-плеер с Play/Pause, полосой перемотки, временем и статусом. Карточка записи показывает только неповторяющиеся описание и данные автора; кнопки записи/остановки получили отдельные состояния. Загрузка и запись по-прежнему открываются поверх упражнения без перезагрузки экрана.


## Версия 1.15

Под текстом логотипа отображается установленная версия приложения. Справа от логотипа появляется компактная кнопка «Обновить», когда проверка GitHub Releases находит APK с более высоким Android `versionCode`. Текущая версия берётся из нативного `BuildConfig` и видна даже без сети; проверка выполняется в фоне, без блокирующего диалога. Кнопка сохраняет своё состояние при переходах между экранами.
