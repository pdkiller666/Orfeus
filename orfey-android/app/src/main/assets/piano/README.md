# Soft upright piano samples

These 12 mono WAV samples are trimmed/resampled derivatives of the `UprightPianoKW-small-SFZ-20190703` bank from FreePats. The source is a recording of a Kawai upright piano and is released under the Creative Commons CC0 1.0 public-domain dedication.

Source: https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html
