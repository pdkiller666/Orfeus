## Срочно: ворота не движутся в опубликованной 1.17; локальный fix candidate 1.18

1. Известный дефект 1.17: шарик реагирует вертикально, но ворота стоят. Причина — отсутствовала синхронизация `game.elapsed`, из которого `drawGame()` выводит координаты ворот.
2. Локальный fix candidate 1.18 записывает elapsed в `updateGameFrame()`; динамический тест исполняет настоящий updater и проверяет, что ворота смещаются влево. 55 Node-тестов, каталог/YIN и Chromium preview прошли; пользовательское Android-устройство пока не проверено.
3. **Следующее действие:** получить/использовать device smoke test установленного APK 1.18: движение ворот и шарика, pitch-поведение, permission, крайние случаи, остановка/результат. Browser preview с fake microphone не заменяет физическую проверку.
4. Candidate `versionName 1.18` находится только в локальном worktree. Не отправлять push в `main` и не запускать публичный Release без отдельного подтверждения владельца точного payload. Существующий signing key не менять.
5. Версия 1.17 остаётся текущим публичным релизом: [build-1032](https://github.com/pdkiller666/Orfeus/releases/tag/build-1032), run [43572175402](https://github.com/pdkiller666/Orfeus/actions/runs/43572175402). Если Android-проверка выявит дополнительные проблемы, объединить их с fix candidate до согласования следующей публикации.

## Ближайшие последующие приоритеты

- **Педагогическая распевка и метроном:** сначала согласовать безопасную последовательность и темпы с педагогом; интегрировать уже существующий метроном, не создавать дубликат.
- **Доступность/устройства:** Android WebView, разрешения, TalkBack, системный font scale, светлая/тёмная тема, ландшафт и несколько телефонов. Browser preview и Node assertions не заменяют физическую проверку.
- **Задержка и качество pitch:** определить измеряемую end-to-end метрику, получить результаты минимум на двух целевых Android-устройствах; не переписывать на Kotlin/AudioWorklet без исходных измерений.
- **Прогресс и бэкап:** проверить чек-листы уроков, сохранение и JSON export/import после перезапуска и между устройствами.
- **Учительские образцы:** подтверждать авторство, согласие, лицензию и педагогическую безопасность; новый аудиофайл в публичной ветке открыт всем до слияния PR. Источником остаётся GitHub-репозиторий, без посреднического backend.
