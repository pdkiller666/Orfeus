# Инструкции для работы с Orfeus

Перед изменением приложения прочитать этот файл, `README.md`, `docs/PROJECT_CONTEXT.md`, `docs/ROADMAP.md` и при работе с рекомендациями — `recommendations-status.md`. После каждой функциональной правки обновлять историю/план в подходящих документах, чтобы рабочий контекст не зависел от переписки.

## Источник кода и структура

- Единственный основной исходный проект Android: `orfey-android/`; HTML/Web Audio живёт в `app/src/main/assets/`, Kotlin/Android — в `app/src/main/`, Node-регрессии — в `tests/`.
- Каталог примеров — `samples/`, проверки данных и аудио — `scripts/`, сборка/публикация — `.github/workflows/build.yml`.
- GitHub `pdkiller666/Orfeus`, ветка `main` — источник истины для исходников, опубликованного APK и активного manifest. Не создавать второй backend/посредника или иной хостинг для образцов без прямого нового запроса владельца проекта.

## Обязательные ограничения

1. **Не трогать ключ подписи** `orfey-android/app/orfey.jks`: не заменять, не пересоздавать, не коммитить новый ключ и не менять signing config. Он обеспечивает обновление поверх существующей установки.
2. **Push в `main` — публикация.** Push автоматически запускает GitHub Actions: тесты, сборку и публичный GitHub Release APK. Не выполнять commit/push, создание release/tag или изменение удалённого репозитория без отдельного явного согласования владельцем точного состава публикации. До этого можно изменять и проверять рабочую копию.
3. **Публичность аудио.** В публичном репозитории аудиофайл становится публичен сразу после загрузки в ветку, до ревью/слияния PR; PR не является приватным. Не обещать обратного и сохранять в UI/документах предупреждение, согласие и подтверждение.
4. **Голосовая безопасность.** Результаты высоты, проценты, игровые попадания и спектральные proxy-метрики не описывать как подтверждённое качество техники, здоровье, безопасность или классификацию голоса. Расщепление и экстремальные техники не включать без педагогического одобрения.
5. UI приложения — на русском; использовать локальный набор SVG вместо emoji. Главные действия «Образец»/«Старт» держать рядом. Сохранять экранную навигацию, доступность, состояние пользователя и дизайн-систему.

## Базовая проверка

```bash
cd orfey-android && node --test tests/*.test.cjs
cd .. && python3 scripts/validate_samples.py
node scripts/test_samples_audio.cjs orfey-android
```

Если доступен Android toolchain, дополнительно собрать `gradle assembleDebug --no-daemon` из `orfey-android/`. Перед публикацией перепроверить `git diff --check`, список файлов, versionName/versionCode и неизменность signing key. Порядок релиза и состояние работ см. в `docs/PROJECT_CONTEXT.md` и `docs/ROADMAP.md`.
