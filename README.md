# Орфей — Android

Полный Android-проект хранится в папке [`orfey-android/`](orfey-android/): исходники Kotlin/JS, Gradle-конфигурация, тесты и существующий ключ подписи. GitHub Actions работает непосредственно из этой папки без промежуточной распаковки ZIP, проверяет каталог и высоту WAV через YIN, собирает APK и публикует его в GitHub Releases и как артефакт workflow `Build APK`.

Начиная с версии 1.15 установленная версия показывается мелким шрифтом под текстом логотипа, а компактная кнопка «Обновить» появляется справа, когда GitHub Releases содержит APK с большим Android `versionCode`. В более ранних версиях 1.4–1.14 используется прежнее окно-предложение. Ссылка открывает страницу APK; установку подтверждает пользователь средствами Android. Это прямое распространение тестового/debug APK, не публикация в Google Play.

В версии 1.5 при ошибке доступа к микрофону приложение объясняет возможную причину и предлагает открыть системные настройки разрешения. Версия 1.6 исправляет строгую проверку origin, которая могла отклонять запрос микрофона до системного диалога. Версия 1.7 заменяет синтетическую кнопку образцом преподавателя, когда соответствующая запись опубликована в основной ветке каталога. Версия 1.8 позволяет выбрать готовый аудиофайл системным Android picker, прослушать и обрезать его, а затем отправить только выбранный WAV-фрагмент. Версия 1.9 исправляет финальное подтверждение отправки образца в WebView и добавляет явное обновление каталога с объяснением, что открытые PR не заменяют синтетический сигнал до слияния в main. Android запрашивает микрофон в момент использования тренажёра или записи, а не при одном только запуске приложения.

Чтобы вручную получить сборку, откройте завершённый запуск Actions для нужного коммита и скачайте артефакт `orfey-apk`, либо откройте список [GitHub Releases](https://github.com/pdkiller666/Orfeus/releases).

Для локальной сборки перейдите в `orfey-android/` и следуйте находящейся там инструкции `README.md`. При выпуске обновления сохраняйте существующий ключ подписи и увеличивайте `versionCode`; не заменяйте и не генерируйте новый ключ.

В [`samples/`](samples/) находятся три небольших синтетических ориентира для проверки «Одной ноты», «Ступеньки До–Ре–До» и упражнения «Диапазон», а также заявленный преподавательский образец для «Одной ноты», добавленный через PR #5. Синтетические WAV — программно синтезированные тоны, не голос человека и не педагогические эталоны; новые записи требуют проверки авторства, согласия, лицензии и педагогической безопасности. Новые реальные записи преподавателей нужно проверять по авторству, согласию исполнителя, лицензии и педагогической безопасности. Учитывайте: в публичном репозитории любой новый WAV становится общедоступным сразу после отправки в ветку приложения, ещё до проверки и слияния PR; PR управляет включением в каталог, а не приватностью аудио. Приложение предупреждает и требует подтверждение перед каждой отправкой. CI проверяет WAV-формат, лимиты, SHA-256 и ожидаемую высоту тестовых сигналов; эти проверки не заменяют педагогическую модерацию.


## Версия 1.10 — опубликована

В запросе публичного manifest удалён вручную добавленный `Cache-Control`: для `raw.githubusercontent.com` он вызывал OPTIONS preflight, на который endpoint отвечает 403; `cache: "no-store"` и уникальный query-параметр сохраняют обновление без такого preflight. На опубликованном main manifest проверена схема 1 и четыре записи, включая teacher sample для упражнения «Одна нота». В уроках добавлен локальный чек-лист по каждому упражнению, общий процент/счётчик и перенос этого состояния через существующий экспорт/импорт. XP продолжает начисляться только по прежней кнопке завершения урока. GitHub Actions run [43471802009](https://github.com/pdkiller666/Orfeus/actions/runs/43471802009) прошёл успешно и опубликовал [Release build-1024](https://github.com/pdkiller666/Orfeus/releases/tag/build-1024), versionCode 1024. Прямая загрузка APK: [orfey-android.apk](https://github.com/pdkiller666/Orfeus/releases/download/build-1024/orfey-android.apk).


## Версия 1.11 — опубликована

Когда для упражнения доступна преподавательская запись, приложение оставляет одну основную жёлтую кнопку Play/Stop. Описание записи и дополнительный нативный плеер находятся в закрытой по умолчанию сворачиваемой панели сразу под кнопкой; при сворачивании во время воспроизведения звук останавливается. Проверки: 33 Node-теста, проверка каталога и 15 YIN pitch regressions прошли в CI. GitHub Actions [43543959489](https://github.com/pdkiller666/Orfeus/actions/runs/43543959489) успешно опубликовал [Release build-1025](https://github.com/pdkiller666/Orfeus/releases/tag/build-1025), Android versionCode 1025. [Скачать APK](https://github.com/pdkiller666/Orfeus/releases/download/build-1025/orfey-android.apk).


## Версия 1.12 — опубликована

Кнопки «Образец» и «Старт» сгруппированы рядом как главные действия упражнения. Описание/плеер и добавление новой записи вынесены в отдельную карточку материалов. Редактор записи открывается нижней панелью поверх текущего экрана; фон не прокручивается, а закрытие панели возвращает к тому же упражнению без его перерисовки. CI прошёл 34 Node-теста, проверку каталога и 15 проверок YIN. Опубликован [GitHub Release build-1026](https://github.com/pdkiller666/Orfeus/releases/tag/build-1026), versionCode 1026; [скачать APK](https://github.com/pdkiller666/Orfeus/releases/download/build-1026/orfey-android.apk).

Навигация, карточки, кнопки образца/старта и аудиозаписи используют общий локальный SVG-набор вместо emoji. ## Версия 1.14 — опубликована

Кнопки «Образец» и «Старт» остаются сгруппированными, но имеют ясную золотую иерархию; активный teacher sample подсвечивает кнопку Play/Stop. ## Версия 1.15 — опубликована

Под названием логотипа показывается установленная версия приложения; справа появляется компактная кнопка «Обновить», только если проверка GitHub Releases находит более новый APK. Проверка не блокирует интерфейс, работает с текущей версией офлайн и восстанавливает кнопку при переходах между экранами. Для версий 1.4–1.14 сохраняется прежний сценарий предложения обновиться.

GitHub Actions [43561631422](https://github.com/pdkiller666/Orfeus/actions/runs/43561631422) успешно завершил build и publish.
