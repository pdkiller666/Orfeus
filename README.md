# Орфей — Android

Исходный Android-проект находится в архиве [`orfey-android.zip`](orfey-android.zip). GitHub Actions распаковывает его, выполняет Node.js-тесты правил приложения, собирает `debug` APK и публикует APK как артефакт workflow `Build APK`.

Чтобы проверить результат, откройте завершённый запуск Actions для нужного коммита и скачайте артефакт `orfey-apk`. Это тестовый APK, не публикация в Google Play.

Для локальной сборки распакуйте ZIP и следуйте инструкции `README.md` внутри `orfey-android/`. При выпуске обновления сохраняйте существующий ключ подписи и увеличивайте `versionCode`; не заменяйте и не генерируйте новый ключ.
