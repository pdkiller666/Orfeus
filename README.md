# Орфей — Android

Исходный Android-проект находится в архиве [`orfey-android.zip`](orfey-android.zip). GitHub Actions распаковывает его, проверяет правила приложения, метаданные и контрольные суммы каталога, сверяет высоту реальных WAV через YIN-детектор приложения, собирает `debug` APK и публикует его как артефакт workflow `Build APK`.

Чтобы проверить результат, откройте завершённый запуск Actions для нужного коммита и скачайте артефакт `orfey-apk`. Это тестовый APK, не публикация в Google Play.

Для локальной сборки распакуйте ZIP и следуйте инструкции `README.md` внутри `orfey-android/`. При выпуске обновления сохраняйте существующий ключ подписи и увеличивайте `versionCode`; не заменяйте и не генерируйте новый ключ.

В [`samples/`](samples/) находятся три небольших синтетических ориентира для проверки «Одной ноты», «Ступеньки До–Ре–До» и упражнения «Диапазон». Это программно синтезированные тоны, не голос человека и не педагогические эталоны. Новые реальные записи преподавателей нужно проверять по авторству, согласию исполнителя, лицензии и педагогической безопасности. Учитывайте: в публичном репозитории любой новый WAV становится общедоступным сразу после отправки в ветку приложения, ещё до проверки и слияния PR; PR управляет включением в каталог, а не приватностью аудио. Приложение предупреждает и требует подтверждение перед каждой отправкой. CI проверяет WAV-формат, лимиты, SHA-256 и ожидаемую высоту тестовых сигналов; эти проверки не заменяют педагогическую модерацию.
