# Каталог аудиообразцов Орфея

`manifest.json` в `main` содержит образцы, включённые в каталог приложения. APK показывает записи только из основной ветки `main`; Pull Request контролирует изменение каталога и попадание в приложение.

**Важно для открытого репозитория:** GitHub делает содержимое каждой ветки публичным. Аудиофайл становится доступен всем немедленно при отправке в upload-ветку — до создания, проверки и слияния PR. PR не является приватной зоной. Удаление файла не гарантирует удаления ранее загруженных/скопированных копий. Приложение явно предупреждает об этом, требует подтверждения для каждой записи и согласия исполнителя.

Имена файлов — UUID, каталог — `samples/audio/`. Публичный manifest и WAV проверяются на SHA-256. Тренерская проверка обязательна для экстремальных вокальных техник; автоматическая валидация проверяет только структуру, размер и целостность файла.

Новые образцы добавляются приложением в отдельную публичную ветку и Pull Request. Сам WAV виден публично до PR; только включение в каталог приложения ждёт review/merge. Чтобы PR-review был обязательным, включите в настройках GitHub для `main` ruleset защиты с Require a pull request и обязательным CODEOWNER review; файл `.github/CODEOWNERS` закрепляет аудиокаталог за владельцем проекта, но сам по себе не включает защиту ветки.
